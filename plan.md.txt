# ODS LAW FIRM — PROJECT CONTEXT

## 1. PROJECT

Nama aplikasi: ODS Law Firm

Project adalah aplikasi Sistem Informasi Hukum untuk Law Firm.

Fitur utama:
- User Management
- Klien
- Perkara
- Lawyer
- Dokumen
- Agenda Sidang
- Dashboard berdasarkan role

Tujuan pengembangan:
Membuat UI/UX lebih modern, clean, profesional, dan user-friendly tanpa merusak backend/functionality yang sudah berjalan.

---

## 20. TEMUAN TERBARU — DASHBOARD ROUTING

Route dashboard utama berada di:

routes/web.php

Route:

Route::get('/dashboard', [DashboardController::class, 'index'])
    ->middleware(['auth'])
    ->name('dashboard');

Dashboard menggunakan:

app/Http/Controllers/DashboardController.php

Saat ini DashboardController BELUM membedakan dashboard berdasarkan role.

Method:

public function index()

mengambil data:

$totalClients
$totalCases
$totalLawyers
$totalHearings
$todayHearings
$recentCases
$upcomingHearings
$recentDocuments

Kemudian mengembalikan:

return view('dashboard', compact(...));

Artinya controller secara eksplisit mencari:

resources/views/dashboard.blade.php

CATATAN PENTING:

Jangan mengasumsikan:

resources/views/users/dashboard.blade.php

adalah view yang digunakan oleh route /dashboard.

Berdasarkan DashboardController yang ditemukan, route /dashboard menggunakan:

resources/views/dashboard.blade.php

DashboardController saat ini juga BELUM memiliki logic:

if role == admin
if role == lawyer
if role == staff

Semua role saat ini menggunakan route /dashboard dan controller yang sama.

## 21. RESOURCE ROUTES

Resource berikut menggunakan Laravel Route::resource:

/hearings
/clients
/lawyers
/cases
/documents

Contoh:

Route::resource('lawyers', LawyerController::class)
    ->middleware('auth');

Sehingga:

/lawyers
    ↓
LawyerController@index
    ↓
kemungkinan besar
resources/views/lawyers/index.blade.php

Begitu juga:

/clients
    ↓
ClientController@index

/cases
    ↓
LegalCaseController@index

/documents
    ↓
DocumentController@index

/hearings
    ↓
HearingController@index

PENTING:

File index.blade.php pada resource seperti lawyers/index.blade.php TIDAK otomatis berarti dashboard role.

Index adalah halaman resource/listing kecuali controller membuktikan sebaliknya.
